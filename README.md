# 🛍️ La Tiendita

Este proyecto fue desarrollado como parte del diplomado de Programación Full Stack.

Es una tienda online que muestra productos variados obtenidos desde una API pública. El diseño es completamente responsive y se adapta a desktop, tabletas y dispositivos móviles.

---

## 🛠️ Herramientas utilizadas

- Astro
- HTML y CSS (con Flexbox y Grid)
- JavaScript para interactividad (búsqueda y carrito)
- API externa: [https://dummyjson.com/products](https://dummyjson.com/products)

---

## ✨ Funcionalidades

- Muestra productos en tarjetas con imagen, nombre, descripción y precio
- Efecto de zoom al pasar el cursor sobre las imágenes
- Diseño responsive para distintos tamaños de pantalla
- Carrito de compras funcional con localStorage (guardar estado entre recargas)
- Filtro en tiempo real para buscar productos

---

## 📦 Instrucciones para ejecutar el proyecto

1. Descargue o clone el repositorio:

```bash
git clone https://github.com/usuario/la-tiendita.git
cd la-tiendita
```

2. Instale las dependencias:

```bash
npm install
```

3. Inicie el servidor de desarrollo:

```bash
npm run dev
```

4. Abra su navegador y acceda a:

```
http://localhost:4321
```
