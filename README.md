
# 🛍️ Tienda Glamour

Este proyecto fue desarrollado como parte del diplomado de diseño y desarrollo web.  
Es una tienda online que muestra productos variados obtenidos desde una API pública. El diseño es completamente adaptable a computadoras, tabletas y dispositivos móviles.

## Herramientas utilizadas

- Astro
- HTML y CSS (con Flexbox)
- API externa: [`https://dummyjson.com/products`](https://dummyjson.com/products)

## Funcionalidades

- Muestra productos en tarjetas con imagen, nombre, descripción y precio
- Efecto de zoom al pasar el cursor sobre las imágenes
- Diseño responsive para distintos tamaños de pantalla

## Instrucciones para ejecutar el proyecto

1. Descargue o clone el repositorio.
2. Abra una terminal y acceda a la carpeta del proyecto:  
   `cd diplomado-ecommerce`
3. Instale las dependencias con el siguiente comando:  
   `npm install`
4. Inicie el servidor de desarrollo ejecutando:  
   `npm run dev`
5. Abra su navegador y acceda a:  
   `http://localhost:4321`
